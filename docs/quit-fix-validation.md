# 完全退出修复：0.2.6 验收记录

## 交付范围

- Windows 显式退出采用资源清理、保持后端根存活、按身份清理所属进程树的两阶段流程。
- 身份通过 PID、创建时间和本次 spawn 时间区间校验；记录已观察到的孤儿，拒绝认领复用 PID。不按进程名称批量结束进程。
- npx 支持请求取消、超时、关闭时封住新任务入口并回收任务树。
- 主进程销毁 UI 的同步异常不再绕过关闭；退出幂等并有独立截止计时器。
- 重启与退出交错不会重新启动后端；退出可中断较长的备份清理等待。强制停止及清理失败不被视作安全备份。
- 修复 Windows node-pty 不支持 POSIX SIGKILL 的旧错误：Windows 强制及延迟终止使用无信号原生终止，POSIX 保留 SIGKILL。
- 保留关闭主窗口隐藏到托盘的行为；没有自动覆盖安装、关闭用户当前实例或写入用户配置。

### 窗口测试条件与问题处理

- 独立 userData、SDK 数据和工作目录位于 `C:/Windows/Temp`；避免用户目录上层 node_modules 掩盖打包依赖缺失。
- 使用两个仅存在于测试目录的离线模型定义验证模型选择器，不使用真实凭据，不发起模型推理请求。设置页面只改内存草稿，不保存用户配置。
- 早期窗口检查发现模型选择器渲染竞态及 `capturePage` 的 `UnknownVizError`。冒烟探针改为等待字段实际挂载；截图设置 stayAwake，仅对该 Viz 错误最多重试两次，持续失败仍记录为失败且保留全部布局断言。
- 最终通过的窗口测试使用默认 GPU 设置，没有以禁用 GPU、跳过截图或减少断言换取通过。截图错误的底层原因未独立证明，不宣称修复了图形驱动。
